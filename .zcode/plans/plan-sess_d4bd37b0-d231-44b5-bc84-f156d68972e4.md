# OneResi — the 5x re-plan

You're right: what shipped so far is plumbing (tokens, pills, memory) and the screens still look like a generic admin template. The new bar: **a screenshot of any single screen, with no context, should read as a designed product** — one bold number per screen, gold money, ruled ledgers, real texture. Per-screen specs below; each screen is screenshot-verified (light + dark, desktop + phone) before the next one starts, and one commit per screen.

## 0. Texture foundations (half a step)
- `type-mega` type step in `tokens.css` + `tokens.ts` (40px mobile / 52px desktop, weight 650) — the hero-figure size. Current max is 34px, too small to dominate a screen.
- `formatPeriod` in `packages/contracts/src/dates.ts` ("2026-09" → "September 2026", UTC-pinned like its siblings) + a contracts test. Every surface stops showing raw period keys.
- Gold stamp pattern for PAID (`bg-gold-soft text-gold border-gold-border` pill), mono receipt numbers (`type-mono`).

## 1. Web Payments → the passbook (signature surface)
Kill the uniform card stack. New structure:
- Eyebrow `PAYMENTS` (uppercase micro, tracked) + display headline that answers the moment: due → "September 2026 is due." / settled → "All settled."
- **Hero band, the one bold number**: `type-mega` Money with `countUp` — total due (accent; critical when overdue) with a Settle CTA, or a gold glowing total-settled figure when nothing is owed. Ring not needed here.
- **Ruled ledger, not cards**: one bordered panel, `divide-y` rows — "September 2026 · ₹3,500 · PAID gold stamp · REC-2026-09-00042 in mono · paid 2 Sep". Receipt links show the actual number.
- Pay dialog keeps method memory; success copy sharpened.

## 2. Desk → bento + dense (the working tool)
- **Overview rebuild**: eyebrow + giant 2-column collections hero (`type-mega` gold countUp + glow, ProgressRing for the rate, trend vs last month, settled-celebration wash when dues hit 0); stat tiles for complaints / gate today / applications; a **pulse strip** line (gate N today · M complaints open · K bookings today).
- Ledger + bookings tables get `dense`, mono receipt numbers, `formatPeriod`; money columns tabular.
- Complaints queue tightened (same cards, denser rhythm). Ctrl-K palette panel goes glass.

## 3. PWA → phone-native
- **BottomTabs → floating glass pill**: detached above the safe area, `bg-surface-glass` + blur, pill shadow, framer-motion `layoutId` sliding indicator, labels on the active tab only.
- Shell header + hero cards pick up the glass/gradient treatment.
- **Billing screen**: total-due hero (`type-mega` scale) + passbook rows mirroring web.
- **Home feed**: dues hero + "N months, settled on time" streak line (only when true) + diary.

## 4. Receipt ceremony (the screenshot moment)
- `receipts/[receiptNo]` becomes dual: **screen** = premium ritual (gold mono receipt number stamps in with rotate+settle, PAID seal lands like a verdict, `type-mega` glowing amount, amount-in-words); **print** = faithful white A5 via a token-based `@media print` block.
- Pay flows get the echo: web dialog + PWA sheet show the receipt number stamping in on success; the paid card/row flashes once.

## 5. Resident web home → bento
Dues hero with household ProgressRing + streak line; waiting card stays on top when someone's at the gate; complaint tracker card; gate feed with relative times. Asymmetric grid — hero wide, feed tall.

## 6. On-time streak (the honest mechanic)
`paymentStreak(invoices)` pure helper in `packages/domain/src/billing.ts` (trailing paid invoices where `paidAt ≤ dueOn`; stops at the first late/unpaid) + vitest suite in `packages/domain/src`. Rendered only when it exists — never shames.

## 7. Dark mode completion
No-flash inline scripts in both root layouts (system-first, `oneresi.theme` persistence, `suppressHydrationWarning`); ThemeToggle in web home header, desk footer, PWA profile; `themeColor` media pair; then a **full dark audit with screenshots of every surface**, fixing anything that assumed light.

## 8. First-run
PWA install card (`beforeinstallprompt`, shown-once, push benefit stated) + desk Ctrl-K shown-once hint.

## 9. Marketing
Rebuilt from real captures of the finished surfaces (hero shot, passbook, desk bento, receipt ritual), "built for Indian societies" section, witty-premium copy, copy-gate clean.

## 10. Final gate
`pnpm typecheck && pnpm lint && pnpm check:copy && pnpm check:enums`, `pnpm test` sequential, `pnpm db:reset && pnpm db:seed`, dev servers, `pnpm test:e2e` → walk green (~118). Full final screenshot sweep in both themes.

**Kept rules**: tokens only, copy/enum gates, no new deps, loading/empty/error everywhere, reduced-motion via `useMotion()`, dev consoles untouched, sequential vitest, one commit per screen.
